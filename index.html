Module 1: Discovery & Feed Engine

High-throughput search and feed indexing portal

Scope & Core Features Chitransh Sain

Manages content discovery and reader traffic routing:

  • Paginated feed APIs with custom sorting (Latest, Trending).
  • Multi-tag filtering (`#Java`, `#FastAPI`, `#Architecture`).
  • Full-text search indexed across titles, abstracts, and tags.
  • Infinite scroll UI layout built with React Query.
Lead Architect: Chitransh Sain Module 1

Engineering Challenge & Solution

Challenge: Database View Counter Bottlenecks

Incrementing article view counts directly in MongoDB on every request created massive database write lockups under heavy traffic.

Solution: Redis Write-Behind Buffer

Implemented an in-memory Redis buffer that aggregates click events in memory and flushes updates to MongoDB in periodic async batches.

Performance Improvement: 92% DB Write Reduction

Module 2: Editor & Writing Suite

Rich technical documentation authoring environment

Scope & Core Features Aaradhya Sharma

Authoring tools tailored specifically for technical content:

  • Split-screen WYSIWYG / Markdown live preview editor.
  • Code block syntax highlighting & inline LaTeX math support.
  • Drag-and-drop image uploads with cloud storage integration.
  • Complete publication lifecycle.
Lead Architect: Aaradhya Sharma Module 2

Engineering Challenge & Solution

Challenge: Background Auto-Save Race Conditions

Frequent background auto-save triggers created out-of-order API responses, resulting in newer drafts being overwritten by older requests.

Solution: Debouncing & Version Locking.

Applied 1.5s client-side request debouncing paired with optimistic document version locking (`@Version`) to reject out-of-order updates.

Concurrency Guarantee: Zero Data Overwrites

Module 3: Profile & Portfolio Aggregator

Dynamic developer portfolio generator with live integrations

Scope & Core Features Aman Raj

Transforms author profiles into verified technical resumes:

  • Aggregated profile dashboard (Bio, Skill Matrix, Post Stats).
  • Live GitHub REST API integration (Pinned Repositories & Stars).
  • Cross-database query bridge connecting PostgreSQL and MongoDB.
  • Exportable dynamic developer resume cards.
Lead Architect: Aman Raj Module 3

Engineering Challenge & Solution:

Challenge: GitHub Rate Limits & Cross-DB Latency.

External API rate limits (HTTP 429) and join latency across SQL and NoSQL databases slowed down profile page load times.

Solution: Parallel Async Execution & Circuit Breaker

Executed parallel async calls via `CompletableFuture` and protected GitHub endpoints using Resilience4j circuit breakers with cached fallbacks.

Latency Reduction: < 350ms Page Response

Engineering Challenge & Solution

Challenge: Bulk Action Lockouts & Dead Feed Links

Hiding multiple spam posts simultaneously risked locking database collections or leaving dead cached links in user feeds.

Solution: Async Batch Flags & Cache Eviction

Applied non-blocking asynchronous batch updates and triggered instant Redis feed cache invalidation hooks upon moderation actions.

Cache Invalidation: < 10ms Global Eviction

Module 5: AI Summarizer & Tag Generator

Automated intelligent content enhancement service

Scope & Core Features Suman Kumar

Powers intelligent automated text augmentation:

  • Automated 2-3 sentence "TL;DR" abstract generation.

Lead Architect: Suman Kumar Module 5

Engineering Challenge & Solution

Challenge: Inference Latency & Save Timeouts

LLM generation takes several seconds; running inference synchronously during article save caused HTTP gateway timeouts on main backend.

Solution: Non-Blocking Background Job Queue

Decoupled article saving from AI inference using Spring `@Async` background queues with graceful fallback handling if LLM is busy.

UX Impact: Zero User Save Delay
